# Custom Fields

Add dynamic custom fields to any Eloquent model without database migrations. Built for Laravel and Filament, Custom Fields provides a complete solution for user-defined data schemas.

## Key Features

- **18+ Field Types**: Text, number, date, select, rich editor, file uploads, and more
- **Conditional Visibility**: Show/hide fields based on other field values
- **Multi-tenancy Support**: Complete tenant isolation and context management
- **Deep Filament Integration**: Forms, tables, infolists, and admin interface
- **Import/Export**: Built-in CSV capabilities for custom field data
- **Security**: Optional field encryption and type-safe validation

Perfect for CRM systems, product catalogs, user profiles, or any application requiring flexible, user-defined data structures.
