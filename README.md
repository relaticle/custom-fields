# Custom Fields Documentation

This branch contains the built documentation for Custom Fields.

## Structure

- `/` - v3 documentation (latest)
- `/v2/` - v2 documentation
- `/v1/` - v1 documentation

## Deployment

Documentation is automatically deployed when changes are pushed to the `3.x`, `2.x`, or `1.x` branches.

Each version builds independently and deploys to its respective folder.
